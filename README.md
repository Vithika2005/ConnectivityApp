# Experiment 8: Connectivity-Based App (React Native)

A cross-platform app (Expo + React Native) that detects whether the device
is online or offline, shows the connection type, and updates automatically
when connectivity changes.

## Features
- Live online/offline indicator (green/red)
- Connection type (Wi-Fi, Cellular, Browser)
- Internet reachability status
- Manual Refresh button
- Vibration and pulse animation on state change

## Tech
- React Native (Expo)
- @react-native-community/netinfo

## Run
```bash
npm install
npx expo start
npx expo start --web
```
Press `a` for Android, `i` for iOS, `w` for web, or scan the QR code with Expo Go.
